# 1. Record architecture decisions

- Status: Accepted
- Date: 2026-10-03
- Deciders: Igris OS Project

## Context

Igris OS is a long-term project spanning kernel-adjacent services, a security
layer, and an AI agent. Decisions made early will be revisited over years;
without a record, rationale is lost and re-litigated.

## Decision

We will record significant architectural decisions as Architecture Decision
Records in `docs/adr/`, using a lightweight MADR-style format. ADRs are
numbered, dated, and immutable once accepted.

## Consequences

- Decisions and their rationale remain discoverable.
- Superseding a decision requires a new ADR, preserving history.
- Minor implementation details are not recorded here.
