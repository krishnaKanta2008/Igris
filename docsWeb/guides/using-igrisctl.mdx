# Using igrisctl

`igrisctl` is the official command-line client for interacting with the Igris OS daemon.

## Installation

Built as part of the Rust workspace:

```bash
cargo build --workspace
# Binary at: ./target/debug/igrisctl
# Release: ./target/release/igrisctl
```

## Global Options

```bash
./target/debug/igrisctl [OPTIONS] <COMMAND>
```

| Option | Short | Description | Default |
|--------|-------|-------------|---------|
| `--socket <PATH>` | `-s` | Unix socket path | `$IGRIS_SOCKET_PATH` or default |
| `--json` | `-j` | Output raw JSON | `false` |
| `--help` | `-h` | Show help | — |
| `--version` | `-V` | Show version | — |

### fs.list

List directory entries.

```bash
./target/debug/igrisctl fs.list --path <PATH> [--max-entries <N>] [--json]
```

| Option | Required | Default | Description |
|--------|----------|---------|-------------|
| `--path` | Yes | — | Absolute path within `IGRIS_FS_ROOT` |
| `--max-entries` | No | 1000 | Maximum entries to return (max 10000) |

**Example:**
```bash
./target/debug/igrisctl fs.list --path ~/.igris/share
./target/debug/igrisctl fs.list --path ~/.igris/share --max-entries 100 --json
```

**Output:**
```
NAME         TYPE        SIZE
file.txt     file        1024
subdir       directory   4096
link.txt     symlink     12  -> file.txt
```

### fs.read

Read file contents (base64 output).

```bash
./target/debug/igrisctl fs.read --path <PATH> [--max-bytes <N>] [--json]
```

| Option | Required | Default | Max | Description |
|--------|----------|---------|-----|-------------|
| `--path` | Yes | — | — | Absolute path within `IGRIS_FS_ROOT` |
| `--max-bytes` | No | 65536 | 1048576 | Maximum bytes to read |

**Example:**
```bash
./target/debug/igrisctl fs.read --path ~/.igris/share/file.txt
./target/debug/igrisctl fs.read --path ~/.igris/share/file.txt --max-bytes 1024
```

**Output:**
```
Content (base64): SGVsbG8gV29ybGQK
Truncated: false
```

**Decode:**
```bash
./target/debug/igrisctl fs.read --path ~/.igris/share/file.txt --json | jq -r '.result.content' | base64 -d
```

### fs.write

Write file (base64 input). **Requires `IGRIS_WRITABLE_PATHS` and `--confirm`.**

```bash
./target/debug/igrisctl fs.write --path <PATH> --content <BASE64> --confirm [--json]
```

| Option | Required | Description |
|--------|----------|-------------|
| `--path` | Yes | Absolute path within `IGRIS_WRITABLE_PATHS` |
| `--content` | Yes | Base64-encoded content |
| `--confirm` | Yes | Must be present (explicit confirmation) |

**Example:**
```bash
# Encode content
echo "Hello Igris" | base64
# SGVsbG8gS3JpcyAK

# Write
./target/debug/igrisctl fs.write \
  --path ~/.igris/share/writable/greeting.txt \
  --content "SGVsbG8gS3JpcyAK" \
  --confirm
```

**Output:**
```
Written: 14 bytes
```

### proc.signal

Send SIGTERM to a process. **Requires `IGRIS_PROCESS_CONTROL=true` and `--confirm`.**

```bash
./target/debug/igrisctl proc.signal --pid <PID> --confirm [--json]
```

| Option | Required | Description |
|--------|----------|-------------|
| `--pid` | Yes | Target process ID |
| `--confirm` | Yes | Must be present |

**Example:**
```bash
# Start daemon with process control
IGRIS_PROCESS_CONTROL=true ./target/debug/igrisd &

# Signal process
./target/debug/igrisctl proc.signal --pid 9999 --confirm
```

**Output:**
```
Signaled: true
```

## Common Patterns

### Using with jq (JSON Processing)

```bash
# Get specific field
./target/debug/igrisctl system.info --json | jq '.result.memory.available_kb'

# Filter processes
./target/debug/igrisctl process.list --json | jq '.result.processes[] | select(.name == "nginx")'

# Format output
./target/debug/igrisctl process.list --json | jq -r '.result.processes[] | "\(.pid)\t\(.name)\t\(.state)\t\(.rss_kb)KB"'
```

### Scripting Examples

#### Backup Script

```bash
#!/bin/bash
# backup-config.sh

set -euo pipefail

SOCKET="${IGRIS_SOCKET_PATH:-$XDG_RUNTIME_DIR/igris/igrisd.sock}"
BACKUP_DIR="$HOME/igris-backups/$(date +%Y%m%d-%H%M%S)"

mkdir -p "$BACKUP_DIR"

# List files to backup
./target/debug/igrisctl fs.list --path ~/.igris/share --json | \
  jq -r '.result.entries[] | select(.type == "file") | .name' | \
  while read -r file; do
    ./target/debug/igrisctl fs.read --path "~/.igris/share/$file" --json | \
      jq -r '.result.content' | base64 -d > "$BACKUP_DIR/$file"
  done

echo "Backup saved to $BACKUP_DIR"
```

#### Process Monitor

```bash
#!/bin/bash
# monitor-process.sh

PID="${1:-1}"
INTERVAL="${2:-5}"

echo "Monitoring PID $PID every ${INTERVAL}s (Ctrl+C to stop)"

while true; do
    result=$(./target/debug/igrisctl process.stat --pid "$PID" --json 2>/dev/null)
    if [ $? -eq 0 ]; then
        state=$(echo "$result" | jq -r '.result.state')
        rss=$(echo "$result" | jq -r '.result.rss_kb')
        name=$(echo "$result" | jq -r '.result.name')
        echo "[$(date '+%H:%M:%S')] $name (PID $PID) - State: $state, RSS: ${rss}KB"
    else
        echo "[$(date '+%H:%M:%S')] Process $PID not found"
        break
    fi
    sleep "$INTERVAL"
done
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `IGRIS_SOCKET_PATH` | Override socket path for client |

```bash
# Use custom socket
IGRIS_SOCKET_PATH=/tmp/custom.sock ./target/debug/igrisctl system.info
```

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | General error (connection, permission, etc.) |
| `2` | Invalid arguments |
| `3` | JSON parsing error (with `--json`) |

## Troubleshooting

### Connection Failed

```bash
# Check socket exists
ls -la $XDG_RUNTIME_DIR/igris/igrisd.sock

# Check daemon running
pgrep -f igrisd

# Test with explicit socket
./target/debug/igrisctl --socket /path/to/socket system.info
```

### Permission Denied

```bash
# Check capability enabled at daemon start
ps aux | grep igrisd
# Look for IGRIS_WRITABLE_PATHS, IGRIS_PROCESS_CONTROL, IGRIS_EVENTS
```

### JSON Output Issues

```bash
# Ensure jq installed
sudo apt install jq  # Ubuntu/Debian
brew install jq      # macOS

# Pretty print
./target/debug/igrisctl system.info --json | jq .
```
