# System Tools

## system.info

Retrieve live kernel and system information from `/proc` and `/sys`.

### Capability Required

None (always available)

### Parameters

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "system.info",
  "params": {}
}
```

### Response Fields

#### kernel

| Field | Type | Description |
|-------|------|-------------|
| `version` | string | Full kernel version string |
| `release` | string | Kernel release (from `uname -r`) |
| `architecture` | string | CPU architecture (e.g., `x86_64`, `aarch64`) |
| `hostname` | string | System hostname |
| `os` | string | Operating system name |
| `platform` | string | Distribution ID (e.g., `ubuntu`, `arch`, `fedora`) |
| `platform_version` | string | Distribution version |

#### cpu

| Field | Type | Description |
|-------|------|-------------|
| `count` | integer | Logical CPU count |
| `model` | string | CPU model name from `/proc/cpuinfo` |
| `mhz` | number | Current CPU frequency in MHz |
| `cache_kb` | integer | L3 cache size in KB |

#### memory

| Field | Type | Description |
|-------|------|-------------|
| `total_kb` | integer | Total physical memory (MemTotal) |
| `available_kb` | integer | Available memory (MemAvailable) |
| `used_kb` | integer | Used memory (estimated) |
| `free_kb` | integer | Free memory (MemFree) |
| `buffers_kb` | integer | Buffer memory (Buffers) |
| `cached_kb` | integer | Cached memory (Cached) |

#### system

| Field | Type | Description |
|-------|------|-------------|
| `uptime_seconds` | integer | System uptime from `/proc/uptime` |
| `load_average.1m` | number | 1-minute load average |
| `load_average.5m` | number | 5-minute load average |
| `load_average.15m` | number | 15-minute load average |

#### igris

| Field | Type | Description |
|-------|------|-------------|
| `version` | string | Igris daemon version |
| `protocol_version` | integer | IPC protocol version |
| `daemon_pid` | integer | Daemon process ID |
| `daemon_uptime_seconds` | integer | Daemon uptime |
| `connections_active` | integer | Active client connections |
| `watches_active` | integer | Active event watches |
| `audit_log_path` | string | Audit log file path |

### igrisctl Usage

```bash
# Human-readable output
./target/debug/igrisctl system.info

# JSON output
./target/debug/igrisctl system.info --json
```

### Data Sources

| Information | Source |
|-------------|--------|
| Kernel version | `/proc/sys/kernel/osrelease`, `uname()` |
| CPU info | `/proc/cpuinfo` |
| Memory info | `/proc/meminfo` |
| Uptime/load | `/proc/uptime`, `/proc/loadavg` |
| Platform | `/etc/os-release` |

### Notes

- All data is read at request time (live)
- No caching; each call reads fresh from `/proc`/`/sys`
- Requires read access to `/proc` and `/sys` (standard on Linux)
- Igris-specific fields reflect daemon internal state
